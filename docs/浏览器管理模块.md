# 浏览器管理模块

## 范围与决策来源

本模块为自托管部署提供内建管理员账户和中英文管理控制台。这是工程默认方案，并非要求用户采用某个身份提供商；OIDC、公开注册和多因素认证未实现。设备凭证、业务服务凭证与浏览器会话是三个独立入口，不能相互代用。

控制台管理当前租户内的应用、设备、注册 grant、连接授权、会话、中继节点和审计。界面使用与业务服务相同的事务约束，但权限来自浏览器专用会话，绝不把服务端密钥交给页面。只读角色不显示变更按钮，服务端仍独立拒绝变更，不能依赖前端隐藏实现权限控制。

## 初始化与部署

1. 应用数据库迁移至包含 `000006_browser_administration` 的版本，数据库运维者先明确创建租户。没有默认账户或密码。
2. 设置 `ADMIN_ORIGIN=https://console.example.test` 为唯一规范 origin；TLS 由可信反向代理终止，保留原始 Host，外部不能直接访问未加密的后端。未设置 `ADMIN_ORIGIN` 时不启用管理页面或浏览器 API。
3. 使用 `device-admin-user create --offline --tenant-id <UUID> --username owner --scope admin --password-stdin` 创建账户。数据库连接配置与迁移工具一致。密码从 stdin 传入，不放到命令行参数、URL、仓库或日志中；应使用受保护的运维终端/秘密输入管道。
4. 账户恢复使用 `device-admin-user change --offline --tenant-id <UUID> --user-id <UUID> --enable`；`--enable` 与 `--disable` 互斥，密码/角色/启用变更均撤销旧会话。
5. 打开 `/admin/` 登录。部署不得创建共享默认账户；`read` 账户只能查询。

显式本机开发可同时设置 `ADMIN_ORIGIN=http://127.0.0.1:<port>` 与 `ADMIN_DEVELOPMENT_LOOPBACK=true`。此例外仅接受 IP 字面量 loopback，不接受任意 HTTP 主机。开发 Cookie 与生产 Cookie 名称不同，不能把开发模式暴露到公网。

## 身份、权限与隔离

- 密码使用 `alexedwards/argon2id` 库：Argon2id、64 MiB、3 次、并行度 2、随机 16 字节盐、32 字节输出；加载存储哈希前先校验参数，避免损坏/恶意参数触发任意内存分配。最低 15 个 Unicode 字符、最多 1024 UTF-8 字节。未找到的账户仍验证相同参数的虚拟哈希。
- 登录计算并发上限为每服务实例 4；数据库持久固定分钟窗口限制全局 120、来源 IP 30、tenant+username 10 次。失败也计数；这些不是分布式风控或抗 DDoS 保证。忽略不可信 X-Forwarded-For；在代理后所有用户可能共享来源 IP 配额，扩容前需明确可信代理与地址解析方案，不能随意相信请求头。
- 256 位随机会话只通过生产 `__Host-peerloom_admin` Cookie 传输：Secure、HttpOnly、SameSite=Strict、Path=/；数据库只存会话 token 的 SHA-256。有效期一小时，账户至多保留 10 个会话。
- 变更必须匹配精确 Origin、Host 和会话绑定 CSRF 头；重复 Cookie/CSRF 头、设备/服务 Bearer 均拒绝。会话续存接口不延长到期时间。
- 管理读写事务取得租户锁并重新校验用户启用状态、当前角色及会话。离线密码重置、禁用、角色修改与删除全部登录会话在同一事务完成；退出只撤销当前会话。角色更改不等待 Cookie 自然过期。
- 浏览器变更使用独立 `admin_management_requests` 表及独立加密 AAD 域，不复用业务服务 receipt。审计记录 `admin_user` 或 `database_operator` 主体，不记录密码、Cookie、CSRF 或一次性 grant 明文。

## 前端边界

控制台是同源静态 TypeScript 应用，不加载第三方脚本，不使用 `innerHTML` 渲染数据。严格 CSP 禁止内联脚本、嵌入与任意外部连接；API 与静态页面设置 no-store/nosniff/no-referrer。登录会话由 HttpOnly Cookie 承载，CSRF 只在内存；localStorage 只保存语言偏好。

所有网络操作异步且有超时，响应读取限制 1 MiB。注册 grant 只在一次性对话框内显示，关闭移除，不写入本地持久存储。剪贴板复制仅由用户点击触发，系统剪贴板残留由用户/操作系统管理，不承诺自动清除。

每个变更对话框生成一次幂等键。结果未知时提供相同键重试，不自动重新创建操作；离开未知结果对话框/页面需要显式确认。幂等 receipt 有保留期，超过保留期仍需查询资源与审计，不应无限盲重试。会话失效后的重新登录不会自动恢复旧变更。

## 构建与验收

`src/admin-web` 固定 TypeScript 与 Playwright 版本并提交 npm lockfile。`npm ci && npm run build` 生成 Go `internal/adminweb/assets` 内嵌产物；部署不需要 Node。必须检查生成文件与来源一致，不能只改编译后 JavaScript。

当前独立开发验证：后端普通 race 与真实 PostgreSQL/HTTP 身份隔离、CSRF、只读授权、同键回放、跨租户拒绝、退出及密码重置均通过；TypeScript 严格构建通过。浏览器真实操作、响应式截图和整仓 CI 仍需完成后更新证据。该文档不代表此独立切片已进入 master。

后续上线边界：没有 OIDC/MFA、外部账户找回、生产渗透测试或认证合规认证；无法把这些未实施项目描述为已完成。
